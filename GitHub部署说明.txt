仓库：PQX-666/essay-atlas
发布源：GitHub Actions，部署 dist/ 目录。

main 分支每次推送后，先运行25项内容和学习流程测试，通过后自动发布网站。
Pull request 只运行测试，不发布。
无需安装npm依赖、无需服务端密钥。

公开的网站包含20篇作文、80张手绘图及练习题。
个人草稿、学习记录和收藏只保存在访问者当前浏览器，不会上传到GitHub。

本地文件和在线网站的浏览器存储互相独立。
迁移已有记录：在旧页面右上角设置中导出备份，再在在线版设置中导入。

本地 Sites 项目标识、实测截图、压缩包、学习备份和缓存均通过.gitignore排除。
网站无需重新处理原图即可部署；build_content.py仅用于保留完整原始素材的本地工作区，不在Actions运行。
